# Musiclib 工具箱

用户已同意工具箱方案，要求保持现有风格并做好每个页面细节。

在桌面侧栏和手机顶栏新增「工具箱」，保留手机底部五项导航。桌面使用右侧工具窗口，手机使用全屏窗口。窗口内有节拍器、和弦查询、简谱编辑器、歌词编辑器四个入口，每个入口有用途说明。

节拍器复用现有引擎，补齐实例归属、输入标签和关闭清理。和弦查询使用现有 ChordEngine，提供常见和弦、根音与类型选择、清晰的指法入口。编辑器使用现有 musictool，打包到独立页面，在新标签页打开选定编辑器，保留诗歌库播放及浏览位置。编辑器资源从现有源文件同步，独立部署时使用入库副本。现有教程需要的 renderer 随页面打包。

所有新增界面沿用 musiclib 的颜色、字体、边框、圆角和深浅主题变量。控件触摸目标至少 44px，窄屏不横溢，支持键盘、可见焦点、Escape、关闭后焦点返回。工具窗口管理浏览器返回，避免误关下层歌曲详情；切换工具或关闭时停止节拍器，歌曲音频由原播放器继续管理。

用户后续要求工具图标参考 StudioLive。卡片采用设备与音乐剪影，箭头保留固定列与内侧留白，手机头部按钮增加安全内距。和弦查询加入移调：可在 −12 至 +12 半音之间调整，也可选择原调根音与目标调根音换算。原始和弦保留，根音与斜杠低音同步移调，和弦类型不变；组成音、键盘、试听和指法显示同一结果。升降号沿用宿主规则，按目标调选择拼写。新查询还原移调，未查询或错误输入时停用移调按钮。

验证四个工具的完整进入、使用和退出路径；在桌面及 320/390px 手机宽度和深色模式检查布局。运行构建、现有简谱/五线谱检查，确认新资源进入发布产物，工具窗口资源进入离线缓存。编辑器离线支持仅在其资源确实可缓存且对应导航返回正确页面时声明。

不调整无关页面，不覆盖已有未提交改动，不在本次请求中发布生产站点。
